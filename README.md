# AM Scientific Calculator

### By Alex Meja

AM Scientific Calculator is an AI-powered scientific
calculator designed to help students, teachers and
professionals solve and understand scientific problems.

## Main Features

- Advanced Scientific Calculator
- AI Mathematical Problem Solver
- Physics Problem Solver
- Chemistry Problem Solver
- Image Question Scanner
- PDF Question Solver
- Graphing Calculator
- Mathematical Formula Library
- Calculation History
- Step-by-Step Explanations

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Python
- SymPy
- NumPy
- Supabase
